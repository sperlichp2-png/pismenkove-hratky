# Písmenkové hrátky

Hra pro prvňáčky: písmenka, slabiky, skládání slov, čtení a matematika do 20.
Ovládání obrázky a hlasem, profily dětí, úrovně, odznaky, denní cíl a odměny.

Hrát: https://sperlichp2-png.github.io/pismenkove-hratky/

- Data dětí se ukládají v prohlížeči zařízení (localStorage).
- Hlas: český hlas zařízení (Nastavení pro rodiče → Hlas). Výslovnost lze doladit v záložce Výslovnost.
